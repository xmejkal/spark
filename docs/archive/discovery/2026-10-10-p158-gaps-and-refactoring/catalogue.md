**How to read the columns.** *statement*: what goes wrong and how it was observed. *evidence*: E a pointer (file:line in
spark unless another repository is named; a command and what it printed; a card number), H a claim with its source only,
D a decision (who, when); — unknown. *source label(s)*: the lens or card ids that saw it; one fault seen by two lenses is
one row. *area*: one of store-levels-and-holds · board-records · needs-matching-vocabulary · chain-and-checks ·
firmware-and-bench · docs-and-recorded-outputs · other. *observed by*: a human typing · an AI agent at the keyboard ·
both · nobody — reasoned only (a code read, nothing run). *severity guess*: harms silently (a wrong result with no
sign) · blocks the journey · misleads · friction · polish — a guess, with one clause why; the council ranks.

**Rules kept.** Nothing here was run against the PO's real store (`~/.local/share/spark`); no spark command was run at
all for this file — every "still on main" is a read of the code at `a8aa34d`, cited by line. Every number carries its
provenance; the count line at the end was computed from this table after it was written. No absolute home paths, no
session ids; a scratch folder is `<scratch>`.
