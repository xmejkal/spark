# P130: the light council before the pull request, 2026-10-12

The change: `scripts/run_scenario.py` runs one scenario of a built project in Wokwi
([#64](https://github.com/xmejkal/spark/issues/64), PR [#174](https://github.com/xmejkal/spark/pull/174)). It waits for
the `ready` text of the firmware. It keeps a dated log of the run. The change is about 100 code lines, so the council was light: one
reviewer on Sonnet, then the refuter on Opus. The refuter read the source of wokwi-cli 0.27.1 and ran nothing against
Wokwi. Each finding is a row in [`INDEX.md`](INDEX.md), WH1 to WH12.
