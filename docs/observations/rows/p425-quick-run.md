# P425: S13, the quick run and the full run, findings rows

Findings from the plan council and the build of P425 (2026-10-26, Prague). Numbers were measured on the PO's Mac (M1, Python 3.10.0) with Chrome running (load average about 4), on commit fa5eb1f: the same tree for both runs.

| # | claim | source | status | evidence / where it went |
|---|---|---|---|---|
| 1 | A budget of 90 s fails the push when the fast lane runs over | plan | rejected | the council: no budget that fails the push. The hook prints the quick run's time and count, and the retro decides any cap (W15b: "a number, not a cap"). `FAST_LANE_BUDGET_SECONDS` and the problems exit are not built |
| 2 | The new runs are called "lanes" | plan | rejected | "lane" already means the expedite lane. The names are "quick run" and "full run": `SPARK_SUITE=quick`, `@slow(reason)` in `tests/suite_runs.py`, and `check_commit.py [commit] --full` |
| 3 | The quick run's line can say `N tests` | plan | rejected | it could be quoted as the suite count. The line is `quick run: Ran N of M tests in S s (K slow tests skipped; the full run is check_commit.py --full)`. K counts only the skips whose reason starts with `slow: `, so a real skip (a missing tool) is not in it. The full run prints `as committed, full run: Ran M tests in S s / OK` |
| 4 | Six classes and modules are slow, marked whole | plan | acted | marked per class or method by the rule "more than about 2 s and a checkable reason": `TheBasicJourneyTest` (12.6 s), `TheLibraryXiaoBuildsAButtonAndAnLedTest` (5.8 s), four classes of `test_mutate.py` (`NearTestsFirstTest` 3.7 s, `StaleBytecodeTest` 3.3 s, `AMutantThatCannotLoadIsRefusedTest` 2.6 s, `AnEscapedMutationTest` 2.1 s), the `test_needs.py` tsci build test (6 to 12 s) and `TscircuitExportTest` (2.1 s). 38 tests in all. The rest of `test_mutate.py` and `test_journey_basic.py` stay in the quick run, each under 2 s. Each reason names what it runs, its seconds and 2026-10-26. A test reads the marks by AST and pins the list |
| 5 | `TheDocsTest` (9.8 s) moves to the full run | plan | rejected | the council: keep it in the quick run if the quick run stays under about 90 s. It does: 77.0 s of tests with it. It stays |
