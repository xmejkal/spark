### Pre-mortem: "It is 2027-05-23, six months after this epic's directions were filed, and they failed. Why?"

1. **The shelf.** On 2026-11-24 five direction epics were filed under P1039 and joined the 43 open epics. Each waited for "after the MVP", as P417 and P419 had waited since 2026-10-26 and P217 and P227 since 2026-10-13. Under W14 no project reached for an eval harness, a second harness or a local model, so none of them entered Ready. In May the open count is past 1,000 at the 30-day rate of RA-10. The directions are titles that no one reads, and the PO still has no picture past the MVP, which was P994 #1449's question too. (Supported by RA-10, RA-11, RA-12; the 1,000 is an extrapolation, H.)
2. **The MVP starved.** The directions got the councils and the Fable runs, about one council-day each (RA-14), on days when the allowance was one council. P934 stayed "waits on the PO". P100 Round A never came back from "Park it". The README Bench row still said "partly" in March. The LangGraph demo ran for the showcase, but no hobbyist journey reached a breadboard wired from the sheet with firmware that works. AGENTS.md:48's bar was broken in the open, one exception at a time. (RA-6, RA-7, RA-8, RA-13.)
3. **The port became a second product.** The team made spark's skills run in Gemini CLI and in Hermes. Each needed its own adapter for the plugin root, the slash commands, `allowed-tools`, the agents' models and the Artifact page (RA-19). After that every spark change needed N doc updates and N checks. The story run and `check_docs.py` grew, and the adapters went stale within two releases while the harness formats moved. Nobody outside used them (RA-1), and the PO went back to Claude Code. The adapters were pruned at a retro, as `match_eval.py` was (RA-17).
4. **The local model could not drive.** On the 8 GiB M1 (RA-21), an 8B model got the `--json` chain right on simple single steps and failed on multi-step ones: a wrong next step, an invented flag, a `null` filled in, which is exactly what never-assume.md forbids. Making it work needed guardrails and retries in the prompts. That is logic written outside the core, against "an agent prompt never repeats its logic" (AGENTS.md:52-54). Or it needed new hardware, a cost the PO did not approve. The direction stopped after one spike. (H from RA-21; the failure modes are those in the Forge and Docker reports.)
5. **The evals measured noise.** An eval of walks was built: fixed tasks, run on Sonnet, Opus and a local model. Run-to-run variation in one model's outcome and tokens was as large as the gap between models, so the model table did not change (RA-18). Each round cost several council-days of tokens (RA-14). When the scripts changed, the fixed tasks broke, and nobody fixed them because no decision read the results. It was pruned under W14 and W16. (RA-17, RA-18; the size of the variance is —.)
6. **The knowledge guard made the skills worse.** A reverse guard forced every script, flag, exit code and JSON key into a skill or command (202 flags, RA-15). The skills grew past their length budgets (P500), so agents loaded more text and picked the wrong command more often. The walks still failed on product behaviour, which the guard does not touch (RA-16). (H; the effect of longer skills on agent success is —.)
7. **The factory wrote behaviour.** "A person's goal becomes a built, tested and deployed thing" pulled spark toward writing firmware and timings in its own code, so that the line could run unattended. That breaks "spark exports facts, never behaviour" and P56 (scrum/VISION.md:78). Unattended deploys pushed against the person's-yes gates, and harnesses with auto-approve skipped the gates that live only in prompts (RA-22). The epic was reversed after a council named the conflict. (H, from VISION.md:78 and RA-22.)
8. **The core was redesigned twice.** A different split of the core from its interfaces (a local server, or a protocol shaped like a language server) was chosen while P793 and P1033 were in flight. The 100-card refactor of #94 reopened and the CLI-first order of 2026-11-16 slipped. The P417 spike, which would have shown that today's split already serves LangGraph and MCP, ran last. (E for the in-flight work: #1105 comments of 2026-11-16 and 2026-11-23; the rest H.)
