## Wiring

### Steps

One connection per step. The board's pins take the rows beside them, so a board pin always gets a jumper.

1. Put the board in the breadboard, each pin in its own row. Holes: b6 to b23, i10 to i23.
2. Put e-paper in the breadboard, each pin in its own row. Holes: e38 to e45.
3. Run a jumper from board 3V3 to the row of e-paper VCC. Holes: from a7 to a45.
4. Run a jumper from board A5 to the row of e-paper D/C. Holes: from j14 to a40.
5. Run a jumper from board D3 to the row of e-paper CS. Holes: from a20 to a41.
6. Run a jumper from board D11 to the row of e-paper Busy. Holes: from j22 to a38.
7. Run a jumper from board D12 to the row of e-paper Reset. Holes: from j21 to a39.
8. Run a jumper from board GND to the row of e-paper GND. Holes: from a9 to a44.
9. Run a jumper from board MO to the row of e-paper SDI. Holes: from a12 to a43.
10. Run a jumper from board SCK to the row of e-paper SCLK. Holes: from a11 to a42.

### Points

After the steps, each line is one point: its ends must be joined, and nothing else.

1. board 3V3 · e-paper VCC (back up, header at the top: the left end pin, above the label VCC)
2. board A5 · e-paper D/C
3. board D3 · e-paper CS
4. board D11 · e-paper Busy (back up, header at the top: the right end pin, above the label Busy)
5. board D12 · e-paper Reset
6. board GND · e-paper GND
7. board MO · e-paper SDI
8. board SCK · e-paper SCLK

## Before you power it

- e-paper: Power VCC from 3.3 V on an ESP32: the silkscreen gives one voltage for supply and IO, and the TXS0108E reads a high only above VCC - 0.4 V on its powered side, so at VCC = 5 V a 3.3 V output may not be read and the panel stays blank.
- e-paper: Set the BS1 switch to L (4-line SPI) for GxEPD2 and other drivers that use D/C: at H the module ignores D/C and the panel shows nothing.
- e-paper: Wait for BUSY to go low before each command: a three-colour full refresh keeps it high for tens of seconds (GxEPD2 allows 27 s), and a command sent meanwhile corrupts the picture.
- e-paper: No fast partial refresh on this three-colour panel: every update redraws and flashes the whole screen, so it suits a picture that changes every few minutes, not a counter or a clock with seconds.
- e-paper: The header's order is printed on the back (VCC GND SDI SCLK CS D/C Reset Busy); from the display side it reads mirrored, so wire by the labels, not by position.
- e-paper: The refresh current and the module's sleep current are not published: measure both before a battery design rests on them.
- e-paper: MicroPython: use a driver for the SSD1675/SSD1680 command set with two planes (the Waveshare 2.9 B V4 file, its pins set for the board); a driver for the IL0373/UC8151 (mcauser epaper2in9b) or a black/white-only one (mattytrentini ssd1675a) shows nothing or no red.
- e-paper: Keep about 9.5 kB of RAM free for the two frame buffers (2 x 4736 bytes) and allocate them before the heap fragments.

Each record whole, with what it asks of the board: `parts.py --show epaper-2in9-bwr-mh-et-live`.
